# 교실용 실시간 QR 퀴즈 게임

카훗(Kahoot) 스타일의 실시간 퀴즈 게임입니다.
선생님이 QR 코드를 띄우면 학생들이 개별로 접속해 문제를 풀고,
**1등부터 마지막까지 실시간 순위**가 선생님 화면에 표시됩니다.

## 특징
- QR 코드로 학생 개별 접속 (방 번호 자동 입력)
- 객관식 + 주관식(단답) 문제 지원
- **정답 + 빠르게 푼 순서(속도 보너스)** 로 점수 계산
- 문제마다 실시간 순위판 표시 (1위~꼴찌), 마지막에 최종 결과

---

## 1. 준비물
- 컴퓨터에 **Node.js** 설치 (https://nodejs.org 에서 LTS 버전)
- 선생님 컴퓨터와 학생 기기가 **같은 Wi-Fi**에 연결되어 있어야 함

## 2. 설치 (최초 1회)
폴더에서 터미널(명령 프롬프트)을 열고:
```
npm install
```

## 3. 문제 편집
`public/host.html` 파일을 열어 위쪽 `QUIZ` 부분을 수정하세요.

```js
const QUIZ = {
  title: "수업 마무리 퀴즈",
  questions: [
    {
      type: "mc",                    // 객관식은 "mc"
      q: "대한민국의 수도는?",
      options: ["서울","부산","대구","인천"],
      answer: 0,                     // 정답 보기 번호 (0=첫번째)
      time: 20                       // 제한시간(초)
    },
    {
      type: "short",                 // 주관식은 "short"
      q: "물의 화학식을 쓰세요.",
      answer: ["H2O","h2o"],         // 허용 정답 여러 개 가능 (공백·대소문자 무시)
      time: 25
    }
  ]
};
```

## 4. 실행
```
npm start
```
실행하면 터미널에 접속 주소가 나옵니다:
```
교사 화면 : http://192.168.0.10:3000/host.html
학생 접속 : http://192.168.0.10:3000/
```

## 5. 수업에서 사용
1. 선생님: 교사 화면 주소(`.../host.html`)를 열어 **화면에 띄웁니다**.
   → QR 코드와 방 번호가 나옵니다.
2. 학생: QR을 찍거나 학생 접속 주소로 들어가 **이름 입력 후 입장**.
3. 참가자가 모이면 선생님이 **[게임 시작]** 클릭.
4. 문제가 나오고, 시간이 끝나거나 **[결과 보기]** 를 누르면 순위판 표시.
5. **[다음 문제]** 로 계속 진행 → 마지막에 최종 순위 발표.

---

## 인터넷으로 배포하고 싶다면
학교 밖 학생도 접속하게 하려면 Render, Railway, Fly.io 같은
무료 Node.js 호스팅에 이 폴더를 올리면 됩니다.
서버는 `PORT` 환경변수를 자동으로 사용하도록 되어 있습니다.
